# Project Statement

## Project Title

Student Grade Management System

## Problem Statement

Manual management of student marks can make searching, calculating results, assigning grades and maintaining records time-consuming and error-prone. A simple Java-based system is required to store student information, validate marks, calculate results consistently, and preserve records between executions.

## Scope

The project manages student academic records for Java, Mathematics and Digital Logic. It supports adding, viewing, searching, deleting and sorting students, calculating results, generating class statistics, persistent file storage and automatic saving.

## Target Users

The system is intended for small classroom or academic environments where a teacher, lab instructor or authorized operator needs a lightweight command-line tool for managing student result records.

## High-Level Features

- Add student
- View students
- Search student
- View result
- Delete student
- Sort by percentage
- Class statistics
- File persistence
- Automatic saving

## Technologies Used

- Java 17+
- Collections Framework (ArrayList, Iterator, Comparator)
- Custom exception handling
- File I/O (BufferedReader, BufferedWriter)
- Threads (Runnable, daemon thread) and synchronization
- Git/GitHub
